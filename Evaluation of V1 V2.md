To note that at this time we had only been taught 2d arrays a little while a go which I then used to extrapolate that 3d arrays must be able to exist and if they exist then you could sort arrays into different categories and place them into a super array which each category could have sub arrays of it’s own.

I Had then wanted of cause to achive the requirements in the section below.

- Linear search the data (both sorted and unsorted)
- sort the data
- provide an analysis for the data

- Compare efficiency of different searches and sorts
